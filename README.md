Hi! I'm **Tanmay** 👋

I enjoy building systems more than building applications.

Whether it's automating infrastructure, deploying Kubernetes workloads, writing Terraform modules, or troubleshooting Linux, I'm happiest when everything just works.

I'm fascinated by the engineering behind modern cloud platforms and love understanding what happens beneath the abstraction layer—from networking and Linux internals to cloud infrastructure and observability.

Outside work, you'll probably find me reading DevOps blogs, watching car reviews, or wishing Tony Stark had open-sourced **JARVIS**.
